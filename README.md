# Крипто-бот для Telegram-канала

Раз в день публикует в канал сводку: цены топ-монет, изменение за 24 ч и 7 дней, лидер и аутсайдер дня, капитализация рынка, доминация BTC, индекс страха и жадности.

Данные бесплатные, без ключей: CoinGecko и alternative.me.

## Пример поста

```
📊 Крипто-сводка на 29.09.2026

🟢 BTC $64 321.50  24ч: +1.80% · 7д: -2.40%
🔴 ETH $2 512.30  24ч: -0.90% · 7д: +3.10%
...
🏆 Лидер дня: XRP (+4.20%)
🧠 Индекс страха и жадности: 62 — Жадность 🤑
```

## Запуск за 10 минут (бесплатно, без сервера)

1. **Создай бота.** В Telegram открой @BotFather → `/newbot` → скопируй токен.
2. **Добавь бота в канал админом** с правом публиковать сообщения.
3. **Создай репозиторий на GitHub** (можно приватный) и загрузи туда все файлы из этой папки, включая `.github/workflows/daily.yml`.
4. **Добавь секреты:** Settings → Secrets and variables → Actions → New repository secret:
   - `BOT_TOKEN` — токен от BotFather
   - `CHANNEL_ID` — `@имя_канала` (для приватного канала — числовой id вида `-100…`)
5. **Проверь:** вкладка Actions → Daily crypto post → Run workflow. Пост должен появиться в канале.

Дальше бот сам будет постить каждый день в 07:00 UTC (09:00 по Вене летом, 08:00 зимой).

## Авто-новости с ИИ (news.py)

Бот 3 раза в день берёт свежую новость из Cointelegraph, CoinDesk, Decrypt и ForkLog, переписывает её на русском своими словами через бесплатный Gemini и публикует пост с картинкой и ссылкой на источник. Рекламу и дубли он пропускает, а опубликованное запоминает в `posted.json`.

**Настройка (добавь к шагам выше):**
1. Зайди на **aistudio.google.com** под Google-аккаунтом → Get API key → Create API key. Карта не нужна.
2. Добавь в GitHub секрет `GEMINI_API_KEY` с этим ключом.
3. Проверь: Actions → Crypto news posts → Run workflow.

**Что можно поменять:**
- **Частота** — строка `cron` в `.github/workflows/news.yml`. Например, `"0 7,10,13,16,19 * * *"` даёт 5 раз в день.
- **Новостей за раз** — `NEWS_PER_RUN` в том же файле.
- **Стиль постов** — добавь в `env` строку `CHANNEL_STYLE: "дерзкий, с юмором, для трейдеров"`.
- **Источники** — список `FEEDS` в начале `news.py`.
- **Модель** — `GEMINI_MODEL`. По умолчанию `gemini-3.5-flash`, при ошибке бот сам переключится на `gemini-3.5-flash-lite`.

> Бесплатный Gemini иногда отвечает ошибкой 429 (лимит). Бот делает паузу и пробует ещё раз. Учти, что Google может использовать запросы бесплатного уровня для улучшения своих моделей. Для новостей это неважно, но личные данные туда не отправляй.

## Настройки

- **Время** — строка `cron` в `.github/workflows/daily.yml`. Например, `"0 16 * * *"` = 16:00 UTC.
- **Монеты** — добавь секрет или переменную `COINS` с id монет CoinGecko через запятую, например `bitcoin,ethereum,dogecoin,pepe`. Id монеты указан в её адресе на coingecko.com.
- **Тест без отправки** — `DRY_RUN=1 python bot.py` просто печатает пост в консоль.

## Запуск на своём VPS (вместо GitHub)

```bash
pip install -r requirements.txt
crontab -e
# добавь строку (каждый день в 9:00 по времени сервера):
0 9 * * * cd /путь/к/crypto-bot && BOT_TOKEN=xxx CHANNEL_ID=@mychannel /usr/bin/python3 bot.py
```

> Имей в виду: GitHub может запускать cron с задержкой до 10–30 минут в часы нагрузки. Если нужна точность до минуты, используй VPS.
